# 🎯 SkillMatch Guidance Assessment System

## 📌 Project Description

SkillMatch Guidance Assessment System is a web-based career guidance platform designed to help **B.Sc. Computer Science students** identify suitable career paths based on their technical skills, interests, and assessment results.

The system provides a skill assessment test and recommends suitable career options along with learning roadmaps to help students plan their career journey.

## ✨ Key Features

* 🔐 **Student Login** – Secure login for students
* 📝 **Skill Assessment Test** – Evaluate technical skills through assessments
* 🎯 **Career Recommendation** – Suggest suitable career paths based on assessment results
* 🗺️ **Learning Roadmaps** – Provide structured learning paths for recommended careers
* 👨‍💼 **Admin Panel** – Manage students, assessments, skills, and career information
* 📊 **Result Dashboard** – Display assessment results and career recommendations
* 💾 **Database Management** – Store student, assessment, and result information

## 🚀 Installation & Setup

1. Download or clone the project.
2. Copy the project folder into:

text
C:\xampp\htdocs\


3. Open **XAMPP Control Panel**.
4. Start **Apache** and **MySQL**.
5. Open phpMyAdmin:

text
http://localhost/phpmyadmin


6. Create the required database.
7. Import the `skillmatch` file.
8. Configure the database connection if required.
9. Open the project in your browser:

text
http://localhost/SkillMatch/
